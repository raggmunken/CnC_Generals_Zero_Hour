Controls & caveats
  • Edge scrolling works by pushing the pointer into the outer few pixels of the picture; the client snaps it onto the exact edge column for you.
  • Ctrl+1…9 (control groups) is reserved by the browser for tab switching unless keyboard lock is active, which requires fullscreen. If the badge below reads keyboard: partial, control groups will switch your tabs instead.
  • Escape reaches the game while keyboard lock is on. Hold it to leave fullscreen.
  • Ctrl+Alt+Q always releases the capture and is never sent to the game.

This page is not in a secure context. WebRTC, pointer lock and keyboard lock all require HTTPS or localhost. Reach the host through an SSH tunnel, or put a TLS proxy in front of it.
